# ಶ್ರೀ ಗಣೇಶ ದಿವ್ಯ ಆಶೀರ್ವಾದ

Enhanced Kannada version:
- Kannada UI and blessings
- Bow detection using MediaPipe Pose
- Layered temple bell generated in-browser
- Soft devotional drone generated in-browser
- Slow, deep, warm Kannada TTS selection
- Automatic reset for the next visitor

For the best voice, install/enable a Kannada male TTS voice on the Android phone.
Host on HTTPS (GitHub Pages works) because camera access is blocked for local content:// HTML files.
