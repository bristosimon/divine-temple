# Sri Ganesha Divine Blessing — Namaste V3

Changes:
- Trigger is now a two-hand Namaste gesture instead of bending.
- Requires both hands to be close together and fingers generally extended upward.
- Gesture must be held briefly to reduce accidental triggers.
- Kannada blessings remain.
- Kannada TTS is selected when available.
- Voice is slower, deeper and more reverent.
- Layered temple bell + devotional drone remain.
- Camera must be served over HTTPS (GitHub Pages works).

Note: the exact voice timbre depends on the Kannada male TTS voice installed/available on the Android phone. For a truly cinematic custom divine voice, a pre-recorded/generated Kannada audio track can be added later.
